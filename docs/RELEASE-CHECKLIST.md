# Чек-лист релиза KVT

Перед публикацией черновика релиза (его создаёт `release.yml` по тегу `vX.Y.Z`).
Прогон — на чистых виртуальных машинах **Windows 10 22H2** и **Windows 11** установщиком
из черновика, не локальной сборкой. Отмечайте `[x]`, проблемы — в Issues со ссылкой
на пункт.

## 0. Перед тегом

- [ ] `version` в `app/src-tauri/tauri.conf.json` и `Cargo.toml` (workspace) — новая.
- [ ] `scripts/update-baseline.json`: `minVersion` и версии компонентов этой
      минимальной версии актуальны (см. комментарий в файле).
- [ ] CI на `main` зелёный (`ci.yml`).
- [ ] Если обновлялся `@tauri-apps/cli` — шаблон `app/src-tauri/windows/installer.nsi`
      перенесён на новую версию (сборка иначе остановится).
- [ ] `docs/ARCHITECTURE.md`: у сделанных шагов — ✅ и пометки «вживую не проверено».

## 1. Сборка

- [ ] `release.yml` прошёл: тесты, `setup.exe`, `offline-setup.exe`, `update.exe`,
      аттестация.
- [ ] SHA-256 в описании черновика совпадают с `Get-FileHash` скачанных файлов.
- [ ] `gh attestation verify <файл> --repo kostiashkaaa/KVT-client` — проходит.

## 2. Установка (чистая машина)

- [ ] SmartScreen: «Подробнее» → «Выполнить в любом случае» — запускается (пока нет подписи).
- [ ] Мастер на русском, лицензия GPL-3.0, картинки на месте; ставится в
      `C:\Program Files\KVT`, один запрос прав.
- [ ] Без WebView2 (Windows 10): обычный установщик докачивает его; офлайн-установщик —
      без интернета.
- [ ] «Службы»: «KVT VPN» — «Автоматически (отложенный запуск)», работает.
- [ ] Первый запуск: подсказки из трёх шагов; «Пропустить» работает.
- [ ] «Настройки» → «Работа в фоне»: «Запускать вместе с Windows» включён.
- [ ] «О программе»: версии KVT, Xray, sing-box, Wintun, Flowseal; кнопки открывают
      страницу загрузки, исходники, папку лицензий (есть `Wintun-LICENSE.txt`).

## 3. Подключение

- [ ] Подписка по ссылке и ключ вручную добавляются; список, флаги, поиск.
- [ ] «Пинг» и «Проверить» по группе.
- [ ] VPN: «Подключить» → сайты открываются, 2ip показывает адрес сервера; строка
      сеанса тикает, трафик растёт.
- [ ] Проверка утечек и DNS — без предупреждений.
- [ ] Kill switch: включить, подключиться, убить ядро в «Диспетчере задач» — интернет
      закрыт, сообщение «Соединение прервано… интернет закрыт»; «Отключить» —
      интернет вернулся.
- [ ] Обрыв: выключить сеть на минуту и включить — VPN поднимается сам; сервер
      перестал отвечать — автопереключение на другой (уведомление).
- [ ] Сон: усыпить машину с подключённым VPN, разбудить — VPN работает, время и
      трафик сеанса не сбросились.
- [ ] Смена сети (Wi-Fi ↔ кабель / другая точка): профиль сети применился.
- [ ] Сеть со страницей входа (гостевой Wi-Fi): «Сеть просит войти», «Отключить VPN».
- [ ] «Почему не работает?» и «Сохранить диагностику» — архив без ключей и адресов.

## 4. Zapret

- [ ] Режим «Гибрид»: YouTube и Discord открываются, остальное через VPN.
- [ ] Режим «Zapret»: без сервера; «Подобрать автоматически» находит стратегию.
- [ ] Вкладка Zapret: проверка, «Обновить» и «Переустановить».
- [ ] Антивирус (Defender, Касперский, если есть): что говорит про WinDivert.

## 5. Трей и фон

- [ ] Значок меняется: отключено / подключение / VPN / Zapret / ошибка.
- [ ] Меню при подключённом VPN: смена сервера, режима, «Что через VPN», стратегии,
      kill switch — переподключается, открытое окно обновляется само.
- [ ] Окно закрыто: уведомления Windows (замена сервера, обрыв), клик открывает окно
      на нужной странице; при открытом окне — сообщение в окне, не уведомление.
- [ ] Сообщения в окне: не больше четырёх, повтор — «×2», сведения гаснут сами, но не
      под мышью; ошибки висят до «Понятно».
- [ ] Окно закрыто 10 минут: kvt.exe — меньше 40 МБ, процессор около нуля,
      процессов `msedgewebview2.exe` от KVT нет.
- [ ] Перезагрузка: KVT в трее без окна; «Подключаться при запуске» — подключается.
- [ ] Длинная подписка (тысячи серверов): главная открывается сразу, при прокрутке
      дорисовывается, поиск без задержек.

## 6. Обновление

- [ ] Поставить прошлую версию, затем `KVT-x.y.z-update.exe`: предупреждение, VPN
      отключается на секунды, после — новая версия в «О программе», настройки и
      подписки на месте, служба работает, автозапуск включён.
- [ ] Полный установщик поверх прошлой версии — без вопроса «удалить перед установкой»,
      данные на месте.
- [ ] `update.exe` на машине без KVT и на версии старше `minVersion` — предлагает
      полную установку, ничего не меняет.
- [ ] Откат: во время обновления служба не поднимается (например, `kvt-service.exe`
      занят антивирусом) — прежняя версия возвращается и работает.

## 7. Удаление

- [ ] «Параметры» → «Приложения» → KVT → «Удалить», с галочкой «Удалить данные
      приложения»: интернет работает, службы «KVT VPN» и драйвера WinDivert
      (`sc query WinDivert`) нет, `C:\Program Files\KVT` и `C:\ProgramData\KVT` удалены,
      автозапуска нет.
