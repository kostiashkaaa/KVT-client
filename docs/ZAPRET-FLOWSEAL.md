# Zapret (Flowseal)

> Этап 4 сделан. Ниже — исходные заметки и то, как это устроено в коде (раздел
> «Реализация» в конце).

Источник: [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Заметки собраны 30.10.2026 по релизу **1.10.4** (20.10.2026). Перед реализацией перепроверить.

## Что берём из релиза

Архив `zapret-discord-youtube-<версия>.zip` с зафиксированной SHA-256
(для 1.10.4: `291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34`).
Скачивается при сборке установщика, не в рантайме.

- `bin/`: `winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, `cygwin1.dll`, фейки `*.bin`.
- `lists/`: `list-general.txt`, `list-google.txt`, `list-exclude.txt`, `ipset-all.txt`, `ipset-exclude.txt`.
- Стратегии: `general.bat` и 20 вариантов (`ALT`…`ALT13`, `EXP`, `FAKE TLS AUTO*`, `SIMPLE FAKE*`).
- `utils/targets.txt` — цели для проверки стратегий.

## Как встраиваем

`service.bat` и `test zapret.ps1` **не вызываем**: они интерактивные и имеют побочные
эффекты:

- включают TCP timestamps через `netsh` при каждом запуске;
- убивают все `winws.exe`;
- удаляют службы `WinDivert` и `GoodbyeDPI`.

Вместо этого:

1. **Стратегии — данные.** Парсер `.bat` извлекает аргументы после `winws.exe`
   (строки склеиваются по `^`, профили разделены `--new`) и превращает их в
   структуру. `%BIN%` и `%LISTS%` подставляет служба: только свои каталоги в
   `Program Files`/`ProgramData`. `%GameFilterTCP%`/`%GameFilterUDP%` — из настроек
   (выключено = `12`).
2. **Whitelist флагов.** Служба отвергает неизвестные флаги и пути вне своих каталогов
   (`--debug=@файл` и подобные), потому что winws работает от SYSTEM.
3. **Единый RoutingPlan.** Домены слоя Zapret дописываются в hostlist.
   **IP VPN-серверов** — в `--ipset-exclude` каждого профиля. Так winws не трогает
   рукопожатие VPN.
4. **Автоподбор стратегии.** Свой тестер вместо `test zapret.ps1`:
   - перебор стратегий на целях из `targets.txt`;
   - HTTP/1.1, TLS 1.2 и TLS 1.3, как у Flowseal;
   - плюс проверка заморозки после 16–20 КБ (`measure_download`);
   - выбор по числу успешных проверок, затем по задержке;
   - результат запоминается для сети;
   - запросы идут через NetGovernor.
5. **Конфликты.** Если найдены служба `zapret` (установленная через `service.bat`),
   `GoodbyeDPI`, `discordfix_zapret`, `winws1`/`winws2` или чужой запущенный `winws.exe`:
   - пользователь видит предупреждение и кнопку «Остановить»;
   - без согласия ничего не удаляем.
6. **Обновления.** Версию сверяем с `.service/version.txt` в репозитории Flowseal.
   Новый релиз приходит с обновлением KVT (хэш зафиксирован), а не скачивается «вживую».

## Известные конфликты

- Касперский детектирует WinDivert как `Not-a-virus:RiskTool.Multi.WinDivert` —
  нужна подсказка про исключение.
- Античиты реагируют на WinDivert.
- Мешают AdGuard, Killer, Intel Connectivity Network Service, Check Point, SmartByte.
- Пути с кириллицей или пробелами ломают `.bat`. У нас пути задаёт служба, но проверить.

## Реализация

- **Комплект** — `scripts/fetch-zapret.ps1`: архив 1.10.4 и `LICENSE.txt` с
  зафиксированными SHA-256, раскладка в `zapret/bin`, `zapret/lists`,
  `zapret/strategies` рядом со службой. Хэши `winws.exe`, `WinDivert.dll`,
  `WinDivert64.sys`, `cygwin1.dll` проверяет и скрипт, и служба перед каждым
  запуском (`kvt_core::zapret::BINARY_HASHES`).
- **Стратегии** — `kvt_core::zapret::parse_bat`: склейка строк по `^`, разбор как в cmd,
  белый список флагов; значения — только порты, числа и режимы либо `%BIN%файл` /
  `%LISTS%файл` без путей. Все 22 стратегии релиза проходят (`tests/real_zapret.rs`),
  `--debug=@файл`, чужие пути и спецсимволы cmd отвергаются.
- **Служба** (`kvt-service/src/zapret.rs`): от приложения приходит только имя
  стратегии. Списки Flowseal копируются в `ProgramData\KVT\zapret` (только SYSTEM и
  администраторы), рядом — свои `*-user.txt`: домены zapret из RoutingPlan, домены и
  IP VPN-серверов в исключениях. winws работает в Job Object вместе с ядром.
- **Гибрид**: winws запускается до ядра и только на физическом интерфейсе
  (`--wf-iface`), чтобы не трогать пакеты внутри TUN. При смене сети KVT
  переподключается.
- **Режим «Zapret»**: только winws, на всех интерфейсах, без ядра и kill switch.
- **TCP timestamps** включаются только для стратегий с `fooling=ts` и только если это
  разрешено в настройках (по умолчанию разрешено, как у Flowseal).
- **Автоподбор** (`app/src-tauri/src/zapret.rs`): сначала проверка без zapret, затем
  стратегии в порядке меню Flowseal до первой, прошедшей все 13 проверок: 6 целей
  Discord и YouTube по TLS 1.3 и TLS 1.2 и загрузка картинки YouTube больше 32 КБ
  (ловит заморозку на 16–20 КБ). Итог запоминается для сети.
- **Конфликты**: службы `zapret`, `GoodbyeDPI`, `discordfix_zapret`, `winws1`, `winws2` и
  процессы `winws.exe`/`goodbyedpi.exe` не из комплекта KVT. Кнопка «Остановить»
  останавливает их, ничего не удаляя.

Не проверено без прав администратора: запуск winws с драйвером WinDivert и автоподбор
на сети, где YouTube и Discord действительно замедляют.

## Вкладка Zapret

- **Состояние и проверка.** «Проверить сейчас» — 13 запросов к Discord и YouTube с текущими
  настройками, итог по каждой цели (TLS 1.3, TLS 1.2) и загрузке больше 32 КБ.
- **«Почему не работает?»** проверяет по шагам: служба, целость комплекта, чужие обходы,
  падение winws, включён ли zapret, мешающие программы (по списку Flowseal: AdGuard,
  Killer, Intel Connectivity Network Service, Check Point, SmartByte, плюс антивирус
  Касперского), системный прокси, TCP timestamps, результат проверки. Итог — одна
  кнопка: переустановить, остановить другие обходы, подобрать стратегию, разрешить
  TCP timestamps или включить zapret (`app/src-tauri/src/zapret.rs`, `conclude`).
- **Автоматически.** Проверка раз в 30 минут и после смены сети; если стратегия
  перестала справляться, в режиме «Zapret» KVT подбирает новую сам, в гибриде —
  предупреждает (подбор остановил бы VPN).
- **Списки.** Свои домены для zapret и домены-исключения (`list-general-user.txt`,
  `list-exclude-user.txt`), обход по IP-списку Flowseal (`ipset-all.txt.backup` →
  `ipset-all.txt`, режим «loaded» у Flowseal).
- **Версия и обслуживание.**
  - «Обновить» — последний релиз Flowseal: SHA-256 архива сверяется с `digest` из API
    GitHub, стратегии — с белым списком, ссылка — только на релизы Flowseal.
    Исполняемые файлы (winws, WinDivert, cygwin1.dll) принимаются, только если их хэш
    есть в `BINARY_HASHES`; иначе остаются прежние, а новые придут с обновлением KVT.
    Обновлённый комплект лежит в `ProgramData\KVT\zapret-bundle` и используется,
    пока он цел.
  - «Переустановить» — удаляет обновление и рабочие списки, проверяет комплект из
    поставки (повреждённый — скачивается заново по зафиксированному хэшу) и удаляет
    службу драйвера WinDivert, чтобы winws поставил её заново. Драйвер не трогается,
    если им пользуется чужой winws.
  - Распаковка — системным `tar.exe`, без отдельной библиотеки zip.
